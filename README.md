## Repository Contents
This repository stores intermediate data dumps resulting from format-parsing and asset-ripping research. 

* **Formats:** `.fbx`, `.obj`, `.blend`, and associated texture maps.
* **Scope:** Character customization assets, environment pieces, and shaders mapped for open-source software testing (e.g., Blender).

## Usage & Research Scope
The materials here are shared to document asset structures, bone rigging frameworks, and texture channel packing methods for reverse-engineering and technical graphics research.
